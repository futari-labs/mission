# Futari Labs site

The Futari Labs website. An immersive 3D site built with React, TypeScript, three.js, and GSAP.

The site is one looping scroll journey: the 二人 landmark, Futari Engineering, Kensaku, a particle installation with links, and a return to the landmark. Scrolling down never reaches an end. `docs/journey.md` describes the sequence and how the transitions work. `docs/identity/README.md` describes the 二人 identity, `docs/construction/README.md` the construction sequences and the ring passage, `docs/exhibits/README.md` the two project exhibits, `docs/environment/README.md` the landscape the journey happens in, `docs/seasons/README.md` how that landscape moves through four seasons in one lap, and `docs/environment-realism/README.md` the banks and trees of the growing seasons.

## Run it

Requirements: Node.js 22.18 or later, pnpm 10, and Google Chrome for the capture tools.

```sh
pnpm install
pnpm dev          # dev server with hot reload
pnpm build        # typecheck, then production build to dist/
pnpm preview      # serve dist/ at http://localhost:4173
pnpm lint
```

Add `?still` to the URL to skip the entrance and hold one fixed frame. Add `?probe` to record frame intervals for `tools/perf.mjs`.

## Regenerate the assets

The landmark, the landscape, the exhibits, and the trees are generated by code. No modeling application is needed.

```sh
pnpm assets:build
```

The command takes about 35 seconds and rewrites the generated files in `public/assets/`. `ONLY=exhibits pnpm assets:build` rebuilds the two exhibits alone. The output is deterministic. It does not touch `land-albedo.jpg` and `land-normal.jpg`, the photographed surface textures: `node tools/assets/textures/fetch.mjs` rebuilds those from their sources, which are listed in `tools/assets/textures/SOURCE.md`.

## Capture and check

Start `pnpm preview` first.

```sh
node tools/capture.mjs docs/journey                 # rest frame of every chapter, desktop and phone
node tools/capture.mjs public/fallback --bare       # the same without text, for the no-WebGL fallback
node tools/journey-test.mjs                         # functional checks
node tools/loop-test.mjs                            # the infinite loop
```

Regenerate `public/fallback/` after any visual change. `docs/journey.md` lists the other tools.
