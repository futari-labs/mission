# Futari Labs site

The Futari Labs website. An immersive 3D site built with React, TypeScript, three.js, and GSAP.

Only the opening scene exists so far: the bridge landmark in its landscape, with an entrance sequence and a pointer response.

## Run it

Requirements: Node.js 22.18 or later, pnpm 10, and Google Chrome for the capture tools.

```sh
pnpm install
pnpm dev          # dev server with hot reload
pnpm build        # typecheck, then production build to dist/
pnpm preview      # serve dist/ at http://localhost:4173
pnpm lint
```

Add `?still` to the URL to skip the entrance and hold one fixed frame.

## Regenerate the assets

The bridge and the landscape are generated by code. No modeling application is needed.

```sh
pnpm assets:build
```

The command takes about 12 seconds and rewrites `public/assets/bridge.glb`, `public/assets/terrain.glb`, and `public/assets/stone-detail.png`. The output is deterministic.

| To change | Edit |
| --- | --- |
| Bridge shape, segments, joints, chips | `tools/assets/bridge.ts` |
| Landscape: platform, foreground ridge, mountains | `tools/assets/terrain-fn.ts` |
| What gets baked into each vertex | `tools/assets/build.ts` |

## Change the look

| To change | Edit |
| --- | --- |
| Copy and links | `src/content/site.ts` |
| Colors, fog, lights, bloom, camera keyframes, pointer and entrance timing | `src/scene/look.ts` |
| Stone, frost, and snow shading | `src/scene/materials.ts` |
| Sky gradient and fog falloff | `src/scene/sky.ts` |
| Entrance sequence | `enter()` in `src/scene/Engine.ts` |
| Type scale, spacing, layout | `src/styles/site.css` |

## Capture screenshots

Start `pnpm preview` first.

```sh
node tools/capture.mjs docs/opening-scene           # desktop and phone stills
node tools/capture.mjs public/fallback --bare       # fallback images without the text overlay
node tools/motion-check.mjs docs/opening-scene      # entrance and pointer contact sheet
```

Regenerate `public/fallback/` after any visual change. Those images show when WebGL is unavailable.
